# Project-3-Resume-Classification

**Business objective-**
* The objective of this project is to build a document classification system that automatically classifies resumes into relevant categories.
This solution helps reduce the manual effort in HR management (HRM) by improving efficiency, accuracy, and automation in the resume screening process.

**🎯 Problem Statement**
Manual resume screening is time-consuming and prone to human bias.
This project aims to:
* Automate resume classification
* Improve hiring efficiency
* Reduce dependency on manual review
* Achieve high accuracy with minimal human intervention

**📁 Dataset Overview:**
The dataset contains resumes in text format belonging to different job categories such as:
* Data Science
* HR
* Engineering
* Sales
* Finance (and others depending on dataset)

**🧠 Approach:**
* Data collection and text preprocessing
* Cleaning (removing stopwords, punctuation, etc.)
* Feature extraction (TF-IDF / Count Vectorizer)
* Model building (Naive Bayes / Logistic Regression / etc.)
* Model evaluation and accuracy improvement

**⚙️ Tech Stack**
* Python 🐍
* Pandas & NumPy
* Scikit-learn
* NLP (Natural Language Processing)
* NLTK / spaCy
* TF-IDF Vectorize

**📊 Key Insights**
* Text preprocessing significantly improves accuracy
* Certain keywords strongly define job categories
* NLP models can effectively automate HR screening tasks

📈 Results
* Achieved high classification accuracy using ML models
* Reduced manual resume screening effort
* Improved consistency in candidate categorization

**📌 Key Learnings**
* Natural Language Processing basics
* Text classification techniques
* Feature engineering for text data
* Real-world application of ML in HR automation
